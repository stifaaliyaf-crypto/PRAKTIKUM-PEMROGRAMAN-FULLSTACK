# Dashboard Manajemen Inventaris Barang Gudang - React 19

Aplikasi web Dashboard Admin interaktif untuk pengelolaan inventaris barang gudang yang dibangun menggunakan React 19, Vite, dan React-Bootstrap guna memenuhi tugas Responsi 1 Pemrograman Fullstack.

## Fitur Utama
* **CRUD Dinamis:** Fitur Create (Tambah barang baru), Read (Tabel data inventaris), Update (Edit informasi/stok barang), dan Delete (Hapus barang).
* **Indikator Status Stok Otomatis:** Sistem secara otomatis akan medeteksi adanya status ketersediaan barang seperti (`Aman`, `Menipis`, atau `Habis`) berdasarkan jumlah stok yang dimasukkan dengan dukungan *badge* warna yang interaktif.
* **Statistik Ringkas:** Kartu informasi untuk memantau total jenis item dan peringatan stok barang.
* **Antarmuka yang Modern & Responsif:** Dibangun menggunakan komponen siap pakai menggunakan `react-bootstrap` dan Bootstrap 5 dengan tampilan tata letak yang rapi di berbagai ukuran layar.
